Departments organize employees within your company. Use the Departments API to set up your organizational hierarchy and keep headcount information current. All department resources belong to your company tenant and are scoped automatically using your authentication token.

<Info>
  **Base URL**
  ```
  https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live
  ```
</Info>

## Authentication

Every request must include the following headers:

| Header | Value |
|---|---|
| `Authorization` | `Bearer <AWS_Cognito_ID_Token>` |
| `x-api-key` | `<static_shared_key>` |

## List Departments

<p>Retrieve a list of departments in your company. Use the optional query parameters to filter results by name or match pattern.</p>

```
GET /company/department/get
```

### Query Parameters

<ParamField query="departmentName" type="string">
  Filter results to departments whose names match this value. The behavior depends on the `matchType` parameter.
</ParamField>

<ParamField query="matchType" type="string">
  Controls how `departmentName` is matched against stored names. Accepted values:
  - `like` — returns departments whose names contain the search string anywhere.
  - `startsWith` — returns departments whose names begin with the search string.

  Omit this parameter to return all departments without filtering.
</ParamField>

### Request Example

<CodeGroup>
```bash cURL
curl --request GET \
  --url "https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company/department/get?departmentName=Eng&matchType=startsWith" \
  --header "Authorization: Bearer <AWS_Cognito_ID_Token>" \
  --header "x-api-key: <static_shared_key>"
```

```js JavaScript
const params = new URLSearchParams({
  departmentName: "Eng",
  matchType: "startsWith",
});

const response = await fetch(
  `https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company/department/get?${params}`,
  {
    method: "GET",
    headers: {
      Authorization: "Bearer <AWS_Cognito_ID_Token>",
      "x-api-key": "<static_shared_key>",
    },
  }
);
const data = await response.json();
```


## Create a Department

<p>Add a new department to your company's organizational structure. You can optionally set an initial headcount and activation state at creation time.</p>

```
POST /company/department/create
```

### Request Body

<ParamField body="departmentName" type="string" required>
  The display name for the new department (e.g. `"Human Resources"`). Must be unique within your company tenant.
</ParamField>

<ParamField body="description" type="string">
  A short description of the department's function or scope. Displayed in admin views and reports.
</ParamField>

<ParamField body="noOfEmployees" type="integer">
  Initial headcount to associate with this department. Defaults to `0` if omitted.
</ParamField>

<ParamField body="isActive" type="boolean">
  Set to `true` to make the department immediately visible in employee-facing interfaces. Defaults to `true`.
</ParamField>

<ParamField body="status" type="string">
  Text status label to assign on creation (e.g. `"Active"`). Defaults to `"Active"` if omitted.
</ParamField>

### Request Example

<CodeGroup>
```bash cURL
curl --request POST \
  --url "https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company/department/create" \
  --header "Authorization: Bearer <AWS_Cognito_ID_Token>" \
  --header "x-api-key: <static_shared_key>" \
  --header "Content-Type: application/json" \
  --data '{
    "departmentName": "Human Resources",
    "description": "Recruitment, onboarding, and employee relations",
    "noOfEmployees": 10,
    "isActive": true,
    "status": "Active"
  }'
```

```js JavaScript

);
const data = await response.json();
```

## Update a Department

<p>Modify an existing department's details. Pass only the fields you want to change — all other fields retain their current values. To soft-delete a department, set <code>isDeleted</code> to <code>true</code>.</p>

```
PUT /company/department/update
```

<Warning>
  Setting `isDeleted: true` soft-deletes the department. Employees assigned to a deleted department will lose their department association. Reassign users before deleting.
</Warning>

### Request Body

<ParamField body="departmentId" type="string" required>
  The unique identifier of the department to update. Retrieve this from `GET /company/department/get`.
</ParamField>

<ParamField body="departmentName" type="string">
  New display name for the department.
</ParamField>

<ParamField body="description" type="string">
  Updated description of the department's function.
</ParamField>

<ParamField body="noOfEmployees" type="integer">
  Updated headcount figure for the department.
</ParamField>

<ParamField body="isActive" type="boolean">
  Set to `false` to deactivate the department and hide it from employee-facing interfaces without deleting it.
</ParamField>

<ParamField body="isDeleted" type="boolean">
  Set to `true` to soft-delete the department. Soft-deleted departments cannot be restored through the API.
</ParamField>

### Request Example

<CodeGroup>
```bash cURL
curl --request PUT \
  --url "https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company/department/update" \

  --header "x-api-key: <static_shared_key>" \
  --header "Content-Type: application/json" \
  --data '{
    "departmentId": "dept_03HXYZ",
    "departmentName": "People & Culture",
    "noOfEmployees": 12,
```
