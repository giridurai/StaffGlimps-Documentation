The Leave Policies API (part of the Company service) lets company admins define leave types, annual allowances, carry-forward rules, and holiday calendars per geographic location. Policies are scoped to a location object so that companies operating across multiple regions or countries can apply distinct rules for each office.

**Base URL:** `https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live`

---

## Authentication

Every request to the Leave Policies API requires both of the following headers:

| Header | Value |
|---|---|
| `Authorization` | `Bearer <AWS_Cognito_ID_Token>` |
| `x-api-key` | `<static_shared_key>` |

## POST /company/leave/create

**Create Leave Policy** — define a new set of leave rules for a specific company location.

Use this endpoint when onboarding a new office location or configuring leave for the first time. Each policy object in the `leavePolicy` array represents one distinct leave type with its own allocation and rules.

### Request Body

<ParamField body="metadata" type="string">
  Must be set to `"leavePolicy"`. This value identifies the resource type being created within the Company service.
</ParamField>

<ParamField body="location" type="object" required>
  The geographic location this policy applies to.
  <Expandable title="location fields">
    <ParamField body="country" type="string" required>
      Country name or ISO 3166-1 alpha-2 code (e.g., `"IN"` or `"India"`).
    </ParamField>
    <ParamField body="province" type="string">
      State or province name (e.g., `"Delhi"`).
    </ParamField>
    <ParamField body="city" type="string">
      City name (e.g., `"New Delhi"`).
    </ParamField>
    <ParamField body="locationName" type="string">
      A human-readable label for the office or location (e.g., `"HQ - New Delhi"`).
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="leavePolicy" type="array" required>
  An array of leave type policy objects. Each object configures one leave type.
  <Expandable title="policy object fields">
    <ParamField body="type" type="string" required>
      Leave type name (e.g., `"Annual"`, `"Sick"`, `"Casual"`, `"Maternity"`).
    </ParamField>
    <ParamField body="perAnnum" type="integer" required>
      Number of leave days allocated per year for this leave type.
    </ParamField>
    <ParamField body="frequency" type="string" required>
      How the allowance is credited — e.g., `"yearly"`, `"monthly"`, or `"quarterly"`.
    </ParamField>
    <ParamField body="carryForward" type="integer" required>
      Maximum number of unused days that can be carried into the next year. Set to `0` to disable carry-forward.
    </ParamField>
    <ParamField body="rules" type="string" required>
      A plain-text description of any special rules or conditions governing this leave type.
    </ParamField>
    <ParamField body="gender" type="string" required>
      Restricts the leave type to a specific gender. Accepted values: `"all"`, `"male"`, or `"female"`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="description" type="string" required>
  A free-text description of the overall leave policy configuration.
</ParamField>

<Tip>
  The `gender` field lets you configure gender-specific leave types such as maternity or paternity leave. Set it to `"female"` for maternity leave, `"male"` for paternity leave, and `"all"` for leave types available to every employee regardless of gender.
</Tip>

## GET /company/leave/get — Holidays

The `GET /company/leave/get` endpoint serves both national and regional holiday data depending on the `metadata` query parameter you provide.

<Tabs>
  <Tab title="National Holidays">

### National Holidays

**Get National Holidays** — fetch the list of nationally observed public holidays for a given country and year.

#### Query Parameters

<ParamField query="metadata" type="string" required>
  Must be `"nationalHolidays"`.
</ParamField>

<ParamField query="year" type="integer" required>
  The four-digit calendar year (e.g., `2024`).
</ParamField>

<ParamField query="country" type="string" required>
  ISO 3166-1 alpha-2 country code (e.g., `"IN"` for India, `"US"` for United States).
</ParamField>

```bash
curl "https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company/leave/get?metadata=nationalHolidays&year=2024&country=IN" \
  -H "Authorization: Bearer <YOUR_COGNITO_ID_TOKEN>" \
  -H "x-api-key: <YOUR_API_KEY>"
```

### Holiday Response Fields

| Field | Type | Description |
|---|---|---|
| `date` | string | Holiday date in `YYYY-MM-DD` format |

### Regional / Province Holidays

**Get Province/Regional Holidays** — fetch holidays specific to a state, province, or city. Use this when your company policy grants region-specific public holidays in addition to national ones.

#### Query Parameters

<ParamField query="metadata" type="string" required>
  Must be `"provinceHolidays"`.
</ParamField>

<ParamField query="year" type="integer" required>
  The four-digit calendar year (e.g., `2024`).
</ParamField>

<ParamField query="country" type="string" required>
  ISO 3166-1 alpha-2 country code (e.g., `"IN"`).
</ParamField>

<ParamField query="province" type="string" required>
  State or province name (e.g., `"Delhi"`).
</ParamField>

<ParamField query="city" type="string" required>
  City name for city-specific holidays (e.g., `"New Delhi"`).
</ParamField>

<ParamField query="locationName" type="string" required>
  The office location name as configured in your leave policy (e.g., `"HQ - New Delhi"`).
</ParamField>

```bash
curl "https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company/leave/get?metadata=provinceHolidays&year=2024&country=IN&province=Delhi&city=New%20Delhi&locationName=HQ%20-%20New%20Delhi" \
```
