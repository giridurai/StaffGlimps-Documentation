Every StaffGlimpse API request (except public document downloads) requires two headers: an AWS Cognito bearer token that identifies the user, and a static `x-api-key` that identifies the client application. This page shows how to obtain the token and construct authenticated requests.

## Required headers

| Header | Value | Required |
| --- | --- | --- |
| `Authorization` | `Bearer <AWS_Cognito_ID_Token>` | Yes |
| `x-api-key` | Static key issued by StaffGlimpse | Yes |
| `Content-Type` | `application/json` (for POST/PUT) | Yes |

<Warning>
  Never commit the `x-api-key` value to a public repository. Store it in environment variables or a secrets manager.
</Warning>

## Obtain a bearer token

StaffGlimpse uses AWS Cognito for user authentication. After a successful login, obtain an ID token via AWS Amplify or the Cognito SDK.

<CodeGroup>

```typescript Amplify (v6)
import { fetchAuthSession } from 'aws-amplify/auth';

const session = await fetchAuthSession();
const token = session.tokens?.idToken?.toString();
```

```javascript AWS SDK v3
import {
  CognitoIdentityProviderClient,
  InitiateAuthCommand
} from '@aws-sdk/client-cognito-identity-provider';

const client = new CognitoIdentityProviderClient({ region: 'ap-south-1' });
const response = await client.send(new InitiateAuthCommand({
  AuthFlow: 'USER_PASSWORD_AUTH',
  ClientId: process.env.COGNITO_CLIENT_ID,
  AuthParameters: {
    USERNAME: 'user@example.com',
    PASSWORD: 'your-password'
  }
}));
const token = response.AuthenticationResult?.IdToken;
```

```python Python (boto3)
import boto3

client = boto3.client('cognito-idp', region_name='ap-south-1')
resp = client.initiate_auth(
    AuthFlow='USER_PASSWORD_AUTH',
    ClientId='YOUR_CLIENT_ID',
    AuthParameters={
        'USERNAME': 'user@example.com',
        'PASSWORD': 'your-password'
    }
)
token = resp['AuthenticationResult']['IdToken']
```

</CodeGroup>

## Make an authenticated request

Use the token and API key in every request. This example fetches the current user profile.

<CodeGroup>

```bash cURL
curl https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile \
  -H "Authorization: Bearer $COGNITO_TOKEN" \
  -H "x-api-key: $STAFFGLIMPSE_API_KEY"
```

```javascript fetch
const res = await fetch(
  'https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile',
  {
    headers: {
      Authorization: `Bearer ${token}`,
      'x-api-key': process.env.STAFFGLIMPSE_API_KEY
    }
  }
);
const data = await res.json();
```

```python requests
import os, requests

resp = requests.get(
    'https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile',
    headers={
        'Authorization': f'Bearer {token}',
        'x-api-key': os.environ['STAFFGLIMPSE_API_KEY']
    }
)
print(resp.json())
```

</CodeGroup>

## Response envelope

Successful responses return HTTP 200 with a standard envelope:

```json Success
{
  "message": "Success",
  "responseCode": 200,
  "response": "Success",
  "result": {
    "firstName": "John",
    "lastName": "Doe",
    "emailId": "john.doe@acme.com",
    "userRole": "ADMIN"
  }
}
```

## Auth errors

| Status | Meaning | Fix |
| --- | --- | --- |
| `401 Unauthorized` | Missing or expired Cognito token | Re-authenticate and retrieve a fresh token. |
| `403 Forbidden` | Missing or invalid `x-api-key` | Confirm the key value with your StaffGlimpse account manager. |

## Token expiration

Cognito ID tokens expire after 60 minutes by default. Use the refresh token stored in the Cognito session to obtain a new ID token before it expires; Amplify handles this automatically when you call `fetchAuthSession()`.
