The Company API manages your top-level organization account. Use it to register a new company tenant, retrieve the company profile, and access billing and plan information. Every call targets the Company base URL and requires both authentication headers described below.

<Info>
  **Base URL**
  ```
  https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live
  ```
</Info>

## Authentication

Every request must include the following headers:

| Header | Value |
|---|---|
| `Authorization` | `Bearer <AWS_Cognito_ID_Token>` |
| `x-api-key` | `<static_shared_key>` |

## Response Envelope

All responses from this API follow a consistent envelope structure:

```json
{
  "message": "Human-readable summary",
  "responseCode": 200,
  "response": "Success",
  "result": { }
}
```

## Get Company Profile

<p>Retrieve the current company's profile, including billing plan details, subscription cycle, domain verification status, and account metadata.</p>

```
GET /company
```

### Request

No request body is required. Include the authentication headers.

<CodeGroup>
```bash cURL
curl --request GET \
  --url "https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company" \
  --header "Authorization: Bearer <AWS_Cognito_ID_Token>" \
  --header "x-api-key: <static_shared_key>"
```

```js JavaScript
const response = await fetch(
  "https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company",
  {
    method: "GET",
    headers: {
      Authorization: "Bearer <AWS_Cognito_ID_Token>",
      "x-api-key": "<static_shared_key>",
    },
  }
);
const data = await response.json();
```

```python Python
import requests

response = requests.get(
    "https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company",
    headers={
        "Authorization": "Bearer <AWS_Cognito_ID_Token>",
        "x-api-key": "<static_shared_key>",
    },
)
data = response.json()
```
</CodeGroup>

### Response Fields

<ResponseField name="CompanyName" type="string">
  The display name of the company as registered in StaffGlimpse.
</ResponseField>

<ResponseField name="Email" type="string">
  The primary admin email address associated with the company account.
</ResponseField>

<ResponseField name="AccountURL" type="string">
  The unique URL slug that identifies the company tenant (e.g. `acme` resolves to `acme.staffglimpse.com`).
</ResponseField>

<ResponseField name="Plan" type="string">
  The active subscription plan (e.g. `Starter`, `Growth`, `Enterprise`).
</ResponseField>

<ResponseField name="Status" type="string">
  Current account status. One of `Active`, `Suspended`, or `Cancelled`.
</ResponseField>

<ResponseField name="BillCycle" type="string">
  Billing frequency for the current plan. One of `Monthly` or `Annual`.
</ResponseField>

<ResponseField name="ExpiringDate" type="string">
  ISO 8601 timestamp indicating when the current billing period or plan expires.
</ResponseField>

<ResponseField name="DomainStatus" type="string">
  Verification state of the company's custom domain. One of `Pending`, `Verified`, or `Failed`.
</ResponseField>

<ResponseField name="Image" type="string">
  URL of the company's logo image, if one has been uploaded. Returns an empty string when no logo is set.
</ResponseField>

<ResponseField name="PaymentMethod" type="string">
  Payment method on file for billing (e.g. `Credit Card`, `Bank Transfer`).
</ResponseField>

<ResponseField name="InvoiceID" type="string">
  Identifier of the most recent invoice generated for this account.
</ResponseField>

## Register a New Company

<p>Create a new company tenant during onboarding. This endpoint provisions a fresh StaffGlimpse workspace and sets up the first admin account.</p>

```
POST /company/register
```

<Note>
  This endpoint does **not** require an `Authorization` header — it is used before a user account exists. You still need to include the `x-api-key` header.
</Note>

### Request Body

<ParamField body="name" type="string" required>
  The display name for your company (e.g. `"Acme Corp"`). This appears throughout the platform UI and in notifications sent to employees.
</ParamField>

<ParamField body="email" type="string" required>
  The email address for the primary admin account. Used for login, billing communications, and account recovery.
</ParamField>

<ParamField body="password" type="string" required>
  The password for the admin account. Must satisfy the platform's password policy (minimum 8 characters, at least one uppercase letter, one number, and one special character).
</ParamField>

<ParamField body="confirmPassword" type="string" required>
  Repeat the password for confirmation. Must exactly match the `password` field. The request is rejected if the two values differ.
</ParamField>

### Request Example

<CodeGroup>
```bash cURL
curl --request POST \
  --url "https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company/register" \
  --header "x-api-key: <static_shared_key>" \
  --header "Content-Type: application/json" \
  --data '{
    "name": "Acme Corp",
    "email": "admin@acme.com",
    "password": "Str0ng!Pass",
    "confirmPassword": "Str0ng!Pass"
  }'
```

```js JavaScript
const response = await fetch(
  "https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company/register",
  {
    method: "POST",
    headers: {
      "x-api-key": "<static_shared_key>",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      name: "Acme Corp",
      email: "admin@acme.com",
      password: "Str0ng!Pass",
      confirmPassword: "Str0ng!Pass",
    }),
  }
);
const data = await response.json();
```

```python Python
import requests

response = requests.post(
    "https://r00buwtnh1.execute-api.ap-south-1.amazonaws.com/live/company/register",
    headers={
        "x-api-key": "<static_shared_key>",
        "Content-Type": "application/json",
    },
    json={
        "name": "Acme Corp",
        "email": "admin@acme.com",
        "password": "Str0ng!Pass",
        "confirmPassword": "Str0ng!Pass",
    },
)
data = response.json()
```
</CodeGroup>

### Response

```json
{
  "message": "Company registered successfully",
  "responseCode": 200,
  "response": "Success",
  "result": {
    "companyId": "cmp_abc123",
    "message": "Registration successful"
  }
}
```

<Tip>
  After registration, authenticate via AWS Cognito to receive the `ID Token` you need for all subsequent API calls. Store both the token and the `x-api-key` securely — rotate them immediately if either is compromised.
</Tip>
