The Users API (served from the Profile service) manages the full lifecycle of employee accounts — from onboarding to offboarding. Every user belongs to your company tenant and can be assigned an `ADMIN` or `USER` role. Use these endpoints to provision new employees, search and filter your workforce, update profile details, and control account access through locking, unlocking, and soft-deletion.

**Base URL:** `https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live`

<Note>
  Every request to the Users API requires two headers: `Authorization: Bearer <AWS_Cognito_ID_Token>` and `x-api-key: <static_shared_key>`.
</Note>

## GET /profile

Retrieve the authenticated user's own profile. No query parameters are required — the caller is identified from the `Authorization` token.

**Endpoint**

```
GET https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile
```

<CodeGroup>

```bash cURL
curl --request GET \
  --url "https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile" \
  --header "Authorization: Bearer <AWS_Cognito_ID_Token>" \
  --header "x-api-key: <static_shared_key>"
```

```javascript JavaScript
const response = await fetch(
  "https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile",
  {
    method: "GET",
    headers: {
      "Authorization": "Bearer <AWS_Cognito_ID_Token>",
      "x-api-key": "<static_shared_key>",
    },
  }
);
const data = await response.json();
```

</CodeGroup>

**Response**

```json
{
  "message": "Success",
  "responseCode": 200,
  "response": "Success",
  "result": {
    "firstName": "Jane",
    "lastName": "Smith",
    "emailId": "jane.smith@acme.com",
    "phoneNumber": "+15550001234",
```

<ResponseField name="result.firstName" type="string">
  The user's first name.
</ResponseField>
<ResponseField name="result.lastName" type="string">
  The user's last name.
</ResponseField>
<ResponseField name="result.emailId" type="string">
  The user's email address, also used as their login identifier.
</ResponseField>
<ResponseField name="result.phoneNumber" type="string">
  The user's phone number (without country code).
</ResponseField>

</ResponseField>

  `true` if the account is active within the tenant.
</ResponseField>
<ResponseField name="result.isDeleted" type="boolean">
  `true` if the account has been soft-deleted.
</ResponseField>
<ResponseField name="result.companyId" type="string">
  The tenant company identifier this user belongs to.
</ResponseField>
<ResponseField name="result.managerName" type="string">
  The full name of the user's assigned manager.
</ResponseField>
<ResponseField name="result.leadName" type="string">
  The name of the team or department lead associated with this user.
</ResponseField>

## GET /profile/get

Search and list employee profiles across your tenant. Apply filters using query parameters to narrow results by email, name, status, or apply sorting and pagination.

**Endpoint**

```
GET https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile/get
```

**Query Parameters**

<ParamField query="emailId" type="string">
  Filter results to the profile matching this email address.
</ParamField>
<ParamField query="firstName" type="string">
  Filter profiles whose first name matches this value (case-insensitive).
</ParamField>
<ParamField query="isActive" type="boolean">
  When `true`, return only active users. When `false`, return only inactive users. Omit to return all.
</ParamField>
<ParamField query="sort" type="boolean">
  When `true`, sort results in ascending alphabetical order by name.
</ParamField>
<ParamField query="limit" type="integer">
  Maximum number of records to return in a single response.
</ParamField>

<CodeGroup>

```bash cURL
curl --request GET \
```

## POST /profile/create

Provision a new employee user account within your company tenant. On success, the API returns the new user's `customerId`, which you must store for all subsequent operations on that profile.

**Endpoint**

```
POST https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile/create
```

**Request Body**

<ParamField body="emailId" type="string" required>
  The employee's email address. Used as their login identifier — must be unique within the tenant.
</ParamField>
<ParamField body="firstName" type="string" required>
  The employee's first name.
</ParamField>
<ParamField body="lastName" type="string" required>
  The employee's last name.
</ParamField>
<ParamField body="password" type="string" required>
  Initial account password. Enforce your organization's password policy here.
</ParamField>
<ParamField body="countryCode" type="string" required>
  The international dialing code for the employee's phone number, e.g. `"+1"` or `"+44"`.
</ParamField>
<ParamField body="phoneNumber" type="string" required>
  The employee's phone number without the country code.
</ParamField>
<ParamField body="userRole" type="string" required>
  Platform role for this user. Must be either `ADMIN` or `USER`.
</ParamField>
<ParamField body="address" type="object" required>
  The employee's address information.
  <Expandable title="address fields">
    <ParamField body="isPhysicalAndMailingAddressSame" type="boolean">
      Set to `true` to use the physical address as the mailing address.
    </ParamField>
    <ParamField body="physicalAddress" type="object">
      The employee's physical (residential) address.
      <Expandable title="physicalAddress fields">
        <ParamField body="addLine1" type="string">
          Street address line 1.
        </ParamField>
        <ParamField body="addLine2" type="string">
          Street address line 2 (apartment, suite, etc.).
        </ParamField>
        <ParamField body="city" type="string">
          City name.
        </ParamField>
        <ParamField body="state" type="string">
          State or province.
        </ParamField>
        <ParamField body="pinCode" type="string">
          Postal / ZIP code.
        </ParamField>
      </Expandable>
    </ParamField>
    <ParamField body="mailingAddress" type="object">
      The employee's mailing address (if different from physical). Same sub-fields as `physicalAddress`.
      <Expandable title="mailingAddress fields">
        <ParamField body="addLine1" type="string">
          Street address line 1.
        </ParamField>
        <ParamField body="addLine2" type="string">
          Street address line 2.
        </ParamField>
        <ParamField body="city" type="string">
          City name.
        </ParamField>
        <ParamField body="state" type="string">
          State or province.
        </ParamField>
        <ParamField body="pinCode" type="string">
          Postal / ZIP code.
        </ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

<CodeGroup>

```bash cURL
curl --request POST \
  --url "https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile/create" \
  --header "Authorization: Bearer <AWS_Cognito_ID_Token>" \
  --header "x-api-key: <static_shared_key>" \
  --header "Content-Type: application/json" \
```

## PUT /profile/update

Update an existing employee's profile information. Supply the `customerId` of the target user along with only the fields you want to change.

**Endpoint**

```
PUT https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile/update
```

**Request Body**

<ParamField body="customerId" type="integer" required>
  The numeric ID of the user to update. Returned by `POST /profile/create`.
</ParamField>
<ParamField body="firstName" type="string">
  Updated first name.
</ParamField>
<ParamField body="lastName" type="string">
  Updated last name.
</ParamField>
<ParamField body="emailId" type="string">
  Updated email address. Must remain unique within the tenant.
</ParamField>
<ParamField body="phoneNumber" type="string">
  Updated phone number (without country code).
</ParamField>
<ParamField body="isActive" type="boolean">
  Set to `false` to deactivate the account without deleting it.
</ParamField>
<ParamField body="userRole" type="string">
  Updated platform role — `ADMIN` or `USER`.
</ParamField>

<CodeGroup>

```bash cURL
curl --request PUT \
  --url "https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile/update" \
  --header "Authorization: Bearer <AWS_Cognito_ID_Token>" \
  --header "x-api-key: <static_shared_key>" \
  --header "Content-Type: application/json" \
  --data '{
    "customerId": 1043,
    "firstName": "Carlo",
    "userRole": "ADMIN"
```


## POST /profile/lock

Lock a user account to immediately prevent the employee from logging in — without permanently deleting their record. Typical use cases include an active investigation, a compliance hold, or a temporary suspension pending HR review.

**Endpoint**

```
POST https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile/lock
```

**Request Body**

<ParamField body="customerId" type="integer" required>
  The numeric ID of the user to lock.
</ParamField>
<ParamField body="lockReason" type="string" required>
  A human-readable explanation for why the account is being locked. This is stored in the audit trail and displayed to administrators who view the user's profile.
</ParamField>

<CodeGroup>

```bash cURL
curl --request POST \
  --url "https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile/lock" \
  --header "Authorization: Bearer <AWS_Cognito_ID_Token>" \
  --header "x-api-key: <static_shared_key>" \
  --header "Content-Type: application/json" \
  --data '{
    "customerId": 1043,
    "lockReason": "Account suspended pending HR investigation — ticket #HR-2024-089"
  }'
```

```javascript JavaScript
const response = await fetch(
  "https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile/lock",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer <AWS_Cognito_ID_Token>",
      "x-api-key": "<static_shared_key>",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      customerId: 1043,
      lockReason: "Account suspended pending HR investigation — ticket #HR-2024-089",
    }),
  }
);
const data = await response.json();
```

</CodeGroup>

**Response**

```json
{
  "message": "User locked successfully",
  "responseCode": 200,
  "response": "Success",
  "result": {
    "message": "User locked",
    "customerId": 1043
  }
}
```

<Warning>
  Locking an account takes effect immediately. The user will be signed out of any active sessions and will not be able to authenticate until the account is unlocked.
</Warning>

## POST /profile/delete

Soft-delete an employee profile, removing it from active listings while preserving the record in the database for audit and compliance purposes. The `deleteReason` is recorded in the audit trail.

**Endpoint**

```
POST https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile/delete
```

**Request Body**

<ParamField body="customerId" type="integer" required>
  The numeric ID of the user to delete.
</ParamField>
<ParamField body="deleteReason" type="string" required>
  A human-readable explanation for the deletion (e.g., employee resignation, contract end). Stored in the audit log.
</ParamField>

<CodeGroup>

```bash cURL
curl --request POST \
  --url "https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile/delete" \
  --header "Authorization: Bearer <AWS_Cognito_ID_Token>" \
  --header "x-api-key: <static_shared_key>" \
  --header "Content-Type: application/json" \
  --data '{
    "customerId": 1043,
    "deleteReason": "Employee resigned on 2024-11-30. Final payroll processed."
  }'
```

```javascript JavaScript
const response = await fetch(
  "https://ak2cemih27.execute-api.ap-south-1.amazonaws.com/live/profile/delete",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer <AWS_Cognito_ID_Token>",
      "x-api-key": "<static_shared_key>",
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      customerId: 1043,
      deleteReason: "Employee resigned on 2024-11-30. Final payroll processed.",
    }),
  }
);
const data = await response.json();
```

</CodeGroup>

**Response**

```json
{
  "message": "User deleted successfully",
  "responseCode": 200,
  "response": "Success",
  "result": {
    "message": "User deleted",
    "customerId": 1043
  }
}
```

<Info>
  This is a **soft delete**. The profile record is marked as deleted and excluded from active queries, but is never permanently removed. Your historical payroll records, attendance logs, and audit trails that reference this `customerId` remain intact.
</Info>
