The StaffGlimpse REST API is split across service-specific AWS API Gateway endpoints in the `ap-south-1` (Mumbai) region. Every request is authenticated with an AWS Cognito bearer token and a static API key. This page covers base URLs, request format, and where to find the full endpoint reference.

</Tip>

## Request and response format

- All requests and responses use `application/json`.
- Every response wraps the payload in a standard envelope:

```json Response envelope
{
  "message": "Success",
  "responseCode": 200,
  "response": "Success",
  "result": { }
}
```

- Timestamps use ISO 8601 in UTC.
- Enum values (leave types, statuses, roles) are uppercase strings.

## Errors

| Code | Meaning |
| --- | --- |
| `400` | Validation error in the request body or query. |
| `401` | Missing or invalid Cognito token. |
| `403` | Invalid `x-api-key`. |
| `404` | Resource not found. |
