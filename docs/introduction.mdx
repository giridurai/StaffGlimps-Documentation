StaffGlimpse is a multi-tenant HR and Payroll SaaS platform that exposes a suite of REST APIs covering every dimension of workforce management — from Company setup and Departments to Roles, Users, Attendance, Leave, Documents, Notifications, and Metadata. Each service domain runs on its own API gateway, giving you fine-grained control and the flexibility to integrate only the capabilities your organisation needs.

## How It Works

StaffGlimpse is organised as a collection of independent API gateways, one per service domain. Every request — regardless of which service you are calling — must include two HTTP headers: an `Authorization: Bearer` header containing a valid AWS Cognito ID token, and an `x-api-key` header containing your static shared API key. All responses share a common envelope shape so that your client code can handle success and error cases uniformly.

```json
{
  "message": "Human-readable summary of the operation",
  "responseCode": 200,
  "response": "Success",
  "result": { }
}
```

The `responseCode` field mirrors the HTTP status code. A value of `200` indicates success; non-200 values describe the specific error condition. The `result` field contains the domain-specific payload for that endpoint.

## Key Concepts

| Concept | Description |
|---|---|
| **Tenant** | A single company account within StaffGlimpse. All data — departments, users, attendance records — is scoped to the tenant that owns it. |
| **User Roles** | Every user is assigned either `ADMIN` or `USER`. Admins can manage company settings, departments, and other users; regular users access their own data and submit requests. |
| **Departments** | Logical groupings of employees within a company. Departments are referenced when creating users and reporting on headcount. |
| **Leave Policies** | Company-defined rules governing leave types, entitlements, and accrual. Policies must exist before employees can submit leave requests. |
| **Attendance Punch-in/out** | Employees sign in and sign out via the Attendance API, optionally providing GPS coordinates and accuracy metadata for location-aware enforcement. |
