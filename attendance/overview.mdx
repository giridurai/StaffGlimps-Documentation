StaffGlimpse Attendance and Leave module gives HR teams and managers complete control over when employees work, how they check in, and how time off is tracked. Whether you run fixed shifts, rotating schedules, or hybrid teams, you can configure rules that match your operations and stay aligned with Indian statutory requirements.

## What you can do

- **Shift management**: Define work timings, grace periods, break rules, and overtime policies for different teams or locations.
- **Check-in methods**: Let employees mark attendance through the web dashboard, mobile app with GPS tagging, or integrated biometric devices.
- **Leave policies**: Create leave types (casual, sick, earned, comp-off, maternity, and more) with accrual, carry-forward, and encashment rules.
- **Holiday calendars**: Build location-specific calendars that distinguish national, optional, and restricted holidays so payroll and leave calculations stay accurate.
- **Regularization**: Allow employees to request corrections for missed punches or forgotten check-ins, with manager approval workflows.

## Key concepts

| Concept | Description |
| --- | --- |
| Shift | A schedule template with start time, end time, break duration, and grace window. |
| Attendance status | Daily outcome such as Present, Absent, Late, Half-day, or On Leave. |
| Leave policy | A rule set that defines eligibility, accrual frequency, balance caps, and approval chain for a leave type. |
| Holiday calendar | A collection of holidays assigned to one or more office locations. |
| Regularization | A correction request raised by an employee for an attendance discrepancy. |
