StaffGlimpse gives your organization a complete HR and payroll foundation through a set of purpose-built REST APIs. Whether you're building a custom HR portal, integrating with an existing system, or automating workforce workflows, StaffGlimpse handles company management, user profiles, attendance tracking, leave policies, document storage, and in-app notifications — all from a single, consistent API surface.

## Get Started in 4 Steps

<Steps>
  <Step title="Authenticate">
    Sign in via AWS Cognito to obtain an ID token. Every API request requires a `Bearer` token and the shared `x-api-key` header. [Learn how →](/docs/authentication)
  </Step>
  <Step title="Register Your Company">
    Call `POST /company/register` with your company name and admin credentials to provision your tenant. [Company Setup Guide →](/docs/guides/company-setup)
  </Step>
  <Step title="Create Departments & Users">
    Set up your org structure with departments and roles, then create employee profiles. [User Management Guide →](/docs/guides/user-management)
  </Step>
  <Step title="Enable Workforce Features">
    Activate attendance tracking and leave policies so employees can start logging time and requesting leave. [Attendance Guide →](/docs/guides/attendance)
  </Step>
</Steps>

<Note>
  All StaffGlimpse APIs are served from AWS API Gateway in the `ap-south-1` (Mumbai) region. See [Base URLs & Endpoints](/docs/endpoints/overview) for a full list of service-specific base URLs.
</Note>
